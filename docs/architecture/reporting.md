# Reporting

```bash
uv run squelch report STUDY_ID --out report.html
```

`reporting/report.py` renders one **self-contained HTML file**: no remote assets, no analytics, no CDN. It reads `study.json` plus every run's `result.json` and `run_spec.json`.

## Sections

1. **Disclosure box.** Always first. Says whether the evidence is scripted or live, and, if a constructed fixture is present, names it.
2. **Header line.** Campaign, backend, model, evidence stage, environment, runner version, config hash, preregistration hash, token usage, spend, and reused-run count.
3. **Status counts.** Every status with its count and the total.
4. **Task success by condition.** Successes, valid N, planned N and rate per task and condition, with the skills each condition exposed. Rates use the *valid* denominator (`completed` + `agent_limit`).
5. **Four-condition interaction analysis.** Appears only when `none`, `a`, `b` and `ab` are all present. Per-task and pooled rows with Wilson intervals, `pair_vs_A`, `pair_vs_B`, the interaction contrast, and ceiling/floor notes.
6. **Fixture provenance.** Where each exposed skill came from, with package hashes. Constructed fixtures are highlighted.
7. **Condition diagnostics.** Median and maximum output tokens and truncated-run counts per condition, so verbosity can't hide behind a success rate.
8. **Runs.** One row per run: status, success, termination reason, model/tool calls, tokens, file changes, and the failed mandatory assertions with their detail text.

## Safe by construction

The template is rendered with Jinja2 **autoescaping on**. Everything that came from the model, a tool, a grader or a diff is escaped. A test injects `<script>alert("x")</script>` into a study and asserts the raw tag never appears in the output. No untrusted Markdown is rendered as HTML.

## Reports for derived studies

Because the report reads `result.json` and `run_spec.json` from the study directory, it works on a study produced by [`replay`](./analysis.md#replay-offline-re-analysis), which carries corrected labels. A derived study doesn't contain per-run traces or diffs; those stay in the source study, so look there for `events.jsonl` and `diff.patch`.
