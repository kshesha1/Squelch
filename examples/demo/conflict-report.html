Condition diagnostics — verbosity and truncation

Loading more instructions lengthens the model's output as well as the prompt, so a condition can fail by hitting an output limit rather than by reasoning worse. Output tokens per run are a total across the run's model calls; compare calls and tokens per call to see whether a condition is wordier per response or just makes more calls. A condition with visibly higher output or any truncated runs is confounded with the limits, and its success rate must not be read as an instruction effect on its own.
